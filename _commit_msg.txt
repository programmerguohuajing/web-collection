fix(replay): 长会话回放播放中途空白 —— 按录制实例锚定合并事件流

根因：同一 base_session_id 下混有多个 rrweb 录制实例（多次页面加载 /
多次 startReplay），而 rrweb 的 node id 空间按录制实例独立。读取侧把整段
会话的所有分段拼成一条时间线，并在某段缺快照时「借用」上一段的旧快照塞入，
导致 rrweb 重建镜像树时 node id 对不上，整条时间线崩坏 → 播放窗口空白。

修复：
- cloudflare/worker.js `replayEvents` 与 apps/api `reassembleReplayEvents`：
  改为「按 session_id（录制实例）分组 + 各自锚定到自身首个全量快照」；快照
  之前的增量丢弃；保留紧邻快照的 Meta(type:4)；实例若无自身快照则整段跳过，
  绝不跨实例借用快照。
- apps/api/repositories/replays-repo.js：详情查询补 select session_id，供按实例分组。
- packages/sdk/src/index.js `startReplay`：建立新录制实例前清空环形缓冲，
  杜绝上一实例的快照/增量跨实例串入。
- test/replay-ingest.test.js：更新契约并新增跨实例隔离回归用例。

验证：真实会话数据上离线对比旧/新逻辑（旧 firstType=3 无快照，新 firstType=2）；
线上 GET /api/replays/<id> 返回 firstType=2、23 快照 / 236 mutation。
